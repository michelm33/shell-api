Release 1.2.0
 
    * New features:

        - core API: _run_check, _makeCd, _navCd, _backCd, _undefined, Int__nears, Int__not0, Int__dec, Int__sumUpSeries, Int__gt,  Int__lt, Float__withinRange, Test__assertDirsShouldNotExist, Test__assertFileSizeGreaterThan, Test__assertNotSameFiles, Math__convertHumanReadableSizeToMiB, Array__prependItems, Array__appendItems, Array__dup, Array__sizeMatch, Map__printKeys, Map__merge, Term__title, User__getLogin, Date__year, Date__date, File__exePath, File__SHA256, File__isExe, File__modificationTimeEpoch, File__writeLines, File__readLines, Str__stretch , Str__align, Str__center, Array__SHA256
        - net API: Net__externalIP, Net__isSSLExpirted
        - dev API: Dev__getBlockDeviceSize, Dev__getAvailableSpace,  
        - pack API : DPKG__isPackageFileInstalled to check if a package which name and version is given by the file name is actually installed.
        - mongo API: mongodb__isURL, mongodb__decodeURL, mongodb__probeShell, mongodb__dump, mongodb__restore, mongodb__dumpVersion, 
        - docker API: dock__isURL, dock__decodeURL, dock__lastImageId, dock__copy: made the copy bidirectional, from container to system , system to container, or container to another container
        - YAML API: YAML__getBatch, YAML__isVoid, YAML__writeFile
        - NEW 'runapi': tool to execute directly any function defined by the shell api
        - NEW 'testapi' which runs 'runapi' and prints OK if execution returned 0 (success) 
        - NEW circular logs: max 15000 lines, with last 2000 taken over in the log, 
        - NEW Array__toTextTableExt as extension of Array__toTextTable to pass dynamic parameters like display of title, colors and alignments

    * Fixes:

        - fixed Math__convertSizeToMiB
        - fixed _setColored
        - fixed in Array__toTextTableExt
        - fixed 2xdouble quote error in generated 'build_release' make target (genapp)
        - fixed Str__escapeChar
        - handling shell-api symlink for genapidoc at package installation
        
    * Improvs/extensions:

        - improved color related functions
        - extended Array__toTextTableExt with line coloring
        - extended Array__print with capability to add prefix and suffix to items        
        - extended Int__dec with optional arg to decrement of the specified amount
        - added Str__progressBar
        - some Math__* functions for converting bytes to readable form
        - extended Int__inc with optional number of increments (1 default)
        - improved runapi and testapi to enable passing refs to variable 
        - worked out CHANGELOG to adoc format to make it usable in online documentation
        - Extended the temp file and dirs API to be able to specify an alternative root folder for temp item
        - Numerous more functions now documented
